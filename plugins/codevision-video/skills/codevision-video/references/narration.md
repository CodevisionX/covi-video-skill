# 내레이션·자막

## 목소리

edge-tts `ko-KR-SunHiNeural`, `--rate=+5%`. 설치 없이 uvx 로 돈다.

```bash
uvx --from edge-tts edge-tts --voice ko-KR-SunHiNeural --rate=+5% --text "…" --write-media assets/vo/s1.mp3
```

`python3 build.py vo` 가 장면 표의 빠진 mp3 를 이렇게 만든다.

## 대본은 한글 발음으로

자막은 영문 그대로, 대본은 읽히는 대로 쓴다. `vo` 의 네 번째 칸이 대본이다.

| 자막 | 대본 |
| --- | --- |
| Covi AX Platform | 코비 에이엑스 플랫폼 |
| Synology Drive | 시놀로지 드라이브 |
| NAS | 나스 |
| Ubuntu | 우분투 |
| NPU NUC | 엔피유 누크 |
| covi model | 코비 모델 |
| USB | 유에스비 |
| AI | 에이아이 |
| OK · NG | 오케이, 엔지 |
| PC | 피씨 |
| 6개 공정 | 여섯 개 공정 |
| RustDesk · HopToDesk | 러스트데스크 · 홉투데스크 (회사에서 부르는 발음) |
| sudo | 수도 |
| 코드비전 로고 | 코드비전 로고 ("회사 로고"라고 쓰지 않는다 — 자막·대본 모두) |

새 단어가 나오면 짧은 샘플을 먼저 뽑아 들어 본다. 요청자가 발음을 지정하면 그대로 따르고 이 표에 더한다(예: NUC 는 "누크").

## 문장

- 해요체, 한 문장에 동작 하나. "~를 골라요", "~가 보이면 끝난 거예요."
- 동작이나 장면 뒤에 이유 한 문장.
  - 가이드: "업로드만 하는 단방향이라, NAS의 파일이 이 PC로 내려오지 않아요."
  - 공정 설명: "부품이 멈춘 순간에 찍어요. 움직이는 중에 찍으면 사진이 흔들려 검사가 안 돼요."
- 뭉뚱그리지 말고 실제 작업 이름으로 쓴다. "절전과 업데이트를 끈다"(X) → "절전 모드와 자동 업데이트를 해제한다"(O).
- 화면에 없는 사실을 말하지 않는다. 받는 곳·준비물처럼 녹화에 없는 정보는 카드 장면을 따로 만들어 보여 주면서 말한다.

## 타이밍

- 다음 내레이션 시작 ≥ 이전 시작 + mp3 길이 + 0.3초. 자막은 `build.py` 가 다음 자막 시작에 맞춰 끊지만, 음성이 겹치면 경고가 나오니 시작을 늦춘다.
- 멈춤 길이는 그 위에서 할 내레이션 길이의 합 + 1초쯤으로 잡는다. mp3 를 먼저 만들고 `ffprobe` 로 길이를 재서 cut.py 의 멈춤 초를 정한다.
- 장면 첫 내레이션은 0.3~0.6초 뒤에 시작해 화면이 먼저 뜨게 한다.
