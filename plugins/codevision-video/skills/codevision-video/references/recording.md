# 원본 영상 다루기

## 받아서 mp4 로 맞추기

어떤 원본이든 먼저 30fps·yuv420p mp4 로 바꿔 `mp4/` 에 둔다. cut.py 는 이걸 전제로 한다. 파일 이름은 찍은 시각이나 짧은 영문(`16-13-47`, `line1-cam1`)으로 둔다.

| 원본 | 변환할 때 주의할 점 |
| --- | --- |
| Ubuntu 내장 녹화(webm, VP8) | ffmpeg 내장 vp8 디코더로 풀면 초록색으로 깨진다. `-c:v libvpx` 를 입력 앞에 둔다. |
| Windows 녹화·OBS(mp4·mkv) | 대개 그대로 된다. 가변 프레임이면 `-r 30` 으로 고정한다. |
| 휴대폰 촬영(mov·mp4) | 세로 영상은 ffmpeg 가 회전 정보를 읽어 세워 준다. 손떨림이 심하면 구간을 짧게 쓴다. |
| 공정·현장 카메라 영상 | fps 가 제각각(10~60)이라 `-r 30` 으로 맞춘다. 흑백이거나 어두우면 `eq=brightness=0.05:contrast=1.1` 정도만 준다. |
| 검사 결과 이미지·스크린샷 | `-loop 1 -t <초>` 로 정지 영상을 만든다. |

```bash
ffmpeg -c:v libvpx -i "raw/녹화.webm" -r 30 -c:v libx264 -crf 16 -pix_fmt yuv420p mp4/16-13-47.mp4   # webm
ffmpeg -i raw/IMG_0412.mov -r 30 -c:v libx264 -crf 16 -pix_fmt yuv420p -an mp4/line1-phone.mp4        # 그 외
```

원본 소리는 쓰지 않는다(cut.py 가 `-an`). 현장 소음 대신 내레이션으로 설명한다.

## 컷 시트로 훑기

전체를 몇 초 간격 썸네일 격자로 보면서 보여 줄 순간, 기다리는 구간, 가릴 것을 타임코드로 적는다.

```bash
ffmpeg -i mp4/16-13-47.mp4 -vf "fps=1/5,scale=480:-1,tile=6x5" -frames:v 1 sheets/16-13-47.png
```

멈출 프레임을 정확히 고를 때는 `-ss` 대신 trim 으로 촘촘히 뽑는다. `-ss` 로 뽑은 시트는 trim 기준과 0.5초쯤 어긋난다. 그 시각으로 멈춤을 걸면 한 박자 앞 화면이 잡힌다.

```bash
ffmpeg -i mp4/16-13-47.mp4 -vf "trim=213:216,fps=4,scale=480:-1,tile=4x3" -frames:v 1 sheets/check.png
```

## 자르기 규칙 (`cut.py`)

- **크기는 짝수**: yuv420 이라 690x555 같은 홀수 크기는 concat 에서 깨진다.
- **한 클립의 조각들은 크기가 같아야** 이어 붙는다. 다르면 `scale`·`pad` 로 맞춘다.
- **멈춤**: tpad 는 길이가 0 으로 나와서 쓸 수 없다. cut.py 는 끝이 `None` 이면 한 프레임을 `loop` 로 늘려 멈춘다.
- **블러**: `("blur", x, y, w, h)` 는 그 영역만 `boxblur=12:2` 로 흐린다. 좌표는 앞 필터(crop)를 거친 뒤 기준이다. 넓은 배경은 `boxblur=24:3,eq=brightness=-0.04` 처럼 필터를 직접 쓴다. 블러가 일부 구간에만 필요하면 그 조각에만 넣는다.
- **보여 줄 부분만 crop**: 창 하나·장비 하나만 보면 되는 장면은 그 영역만 잘라 크게 보여 준다. 테두리까지 남겨서 무엇을 잘랐는지 알 수 있게 한다.
- **PC 터미널 녹화**: 독·상단바를 잘라 내고, 글자가 가장자리에 붙지 않게 터미널 색 여백을 덧댄다(스타터의 `TERM`). 안 그러면 카드 모서리에서 글자가 잘린다.
- **깜빡임**: 창 전환 순간의 흰 화면 같은 건 그 0.5초를 조각 사이에서 빼 버린다.

## 배속 고르기

| 구간 | 배속 |
| --- | --- |
| 입력·클릭, 부품이 한 번 지나가는 순간 | 1배속(필요하면 0.5배속) |
| 반복 동작이 이어지는 구간 | 2~4배속 |
| 다운로드·빌드·설비 대기 | 12~24배속. 칩에 "실제 N분 N초" |
| 꼭 봐야 하는 순간 | 멈춤. 내레이션 길이만큼(4~15초) |

## 검수할 때 볼 것

- 강조 표시가 멈춘 프레임의 대상 위에 정확히 있는지
- 자막이 화면 아래쪽 내용을 가리지 않는지
- 블러가 가릴 것을 처음부터 끝까지 덮는지. 대상이 움직이면 구간을 나눠 좌표를 다시 잡는다.
- 가려야 할 정보가 한 프레임이라도 보이지 않는지
