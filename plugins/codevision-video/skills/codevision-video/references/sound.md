# 배경음악·효과음

외부 음원을 쓰지 않는다. 배경음악은 `bgm.py`, 효과음은 `sfx.py` 가 numpy 로 직접 합성한다. 저작권·라이선스를 따질 일이 없고, 곡이 영상 길이에 맞춰 늘어난다.

## 만드는 순서

```bash
python3 build.py vo    # 내레이션
python3 build.py bgm   # 배경음악(assets/bgm.mp3)과 효과음(assets/sfx.mp3)
python3 build.py       # index.html. 두 mp3 가 있으면 트랙 5·7 에 넣는다
```

- `bgm` 은 내레이션 시각을 보고 배경음을 줄이고, 장면 시각을 보고 효과음을 놓는다. 내레이션이나 장면 길이를 바꿨으면 `bgm` 부터 다시 돌린다. 안 그러면 배경음이 엉뚱한 곳에서 줄어든다.
- 두 mp3 가 없으면 소리 없이 만들어진다. 시안 단계에서 음악 없이 보고 싶을 때는 두 파일을 지우면 된다.

## 배경음악

코드비전 기본곡이다. 밝은 팝 반주라 설명 영상 아래에 깔아도 내레이션과 부딪히지 않는다.

| 항목 | 값 |
| --- | --- |
| 조·빠르기 | G장조, 112BPM |
| 악기 | 킥, 클랩, 하이햇, 베이스, 플럭(좌우), 패드, 벨 멜로디 |
| 구성 | 인트로 4마디(드럼 없음) → 벌스 8 → 코러스 8(멜로디) → 브리지 8 → 코러스 8 → 브레이크 4 → 벌스 8 → 코러스 8. 영상이 더 길면 벌스부터 되풀이한다 |
| 음량 | `LEVEL` 0.55. 처음 1초 페이드 인, 끝 3초 페이드 아웃 |
| 내레이션 중 | `DUCK` 0.22배. 내레이션 0.15초 전부터 끝나고 0.2초 뒤까지, 0.3초에 걸쳐 부드럽게 줄였다 되돌린다 |

- 화성, 빠르기, 악기, 난수 시드(`RNG` 7)를 바꾸지 않는다. 하나만 바꿔도 다른 곡이 되고, 영상마다 음악이 달라진다.
- 요청자가 다른 분위기를 원하면 그 영상 폴더의 `bgm.py` 만 고친다. 스타터는 건드리지 않는다.
- "배경음이 크다·작다"는 `LEVEL`, "말할 때 음악이 거슬린다"는 `DUCK` 을 고친다. 0.22 는 실제 교육 영상을 소리 켜고 검토하며 맞춘 값이다.

## 효과음

다섯 가지만 쓴다. 장면이 바뀌거나 무언가 새로 나타나는 순간에만 짧게 울려서, 보는 사람의 눈을 그쪽으로 끈다.

| 소리 | 울리는 때 | 붙는 곳 | 음량 |
| --- | --- | --- | --- |
| `whoosh` 휙 | 장면이 바뀌기 0.3초 전 | `scenes()` 가 자동으로 | 0.14 |
| `chime` 차임(벨 네 음이 올라감) | 첫 장면에 로고가 뜰 때 | `title` | 0.34 |
| `pop` 톡 | 주황 강조가 뜰 때, 흐름도 칸이 켜질 때 | `clip` 의 `marks`, `flow` | 0.16 |
| `click` 딸깍 | 화면 위 마우스가 누를 때 | 마우스를 그리는 장면에서 직접 | 0.30 |
| `alert` 알림(두 음이 내려감) | 불량(NG)이 처음 뜰 때 | NG 를 보여 주는 장면에서 직접 | 0.30 |

- 새 장면 kind 를 만들면 위 기준대로 `SFX.append((영상 기준 절대 초, "종류"))` 를 넣는다. 장면 함수 안에서 넣으면 `bgm` 명령이 모아 간다.
- 다섯 가지 외의 소리를 더하지 않는다. 음량도 위 값 그대로 둔다. 효과음이 내레이션보다 튀면 설명이 묻힌다.
- 같은 불량이 다음 장면까지 이어지면 `alert` 를 다시 내지 않는다. 새 불량이 또 나온 것처럼 들린다.
- 로고로 끝맺는 장면을 따로 만들면 로고가 뜰 때 `chime` 을 한 번 더 넣는다. 처음과 끝이 같은 소리로 묶인다.
- 소리만 들어 보려면 `python3 sfx.py test.mp3` 를 돌린다. 다섯 가지가 1초 간격으로 나온다.

## 내레이션 속도

기본은 `+5%` 다. 현장 작업자 교육처럼 화면을 처음 보는 사람 앞에서 트는 영상은 `VOICE` 를 `+0%` 로 낮춘다. 현장 교육 영상을 소리 켜고 검토했을 때 `+5%` 는 따라가기 조금 빠르다는 의견이 나왔다.
